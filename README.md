# Эмулятор UNIX shell

## 1. Общее описание

Проект представляет собой эмулятор командной строки
UNIX-подобной операционной системы на Python.

На текущем этапе реализованы:

- режим REPL;
- разбор команд и аргументов;
- команды `ls`, `cd` и `exit`;
- обработка неизвестных команд;
- параметры командной строки;
- конфигурационный файл JSON;
- выполнение стартового скрипта;
- загрузка виртуальной файловой системы (VFS) в память.

Команды `ls` и `cd` пока являются заглушками и выводят
свое имя и переданные аргументы.

## 3. Запуск и настройки

Обычный запуск:

    .\run.bat

Поддерживаются параметры:

- `--vfs` – путь к директории VFS;
- `--script` – путь к стартовому скрипту;
- `--config` – путь к конфигурационному файлу.

Пример:

    .\run.bat --vfs tests\vfs_deep --script tests\start3.txt

Пример `config.json`:

    {
        "vfs": "tests/vfs_deep",
        "script": "tests/start3.txt"
    }

Значения из конфигурационного файла имеют приоритет над
параметрами командной строки.


## 4. Команды

### `ls`

На текущем этапе является заглушкой.

    VFS:~$ ls
    ls []

### `cd`

На текущем этапе является заглушкой.

    VFS:~$ cd folder
    cd ['folder']

### `exit`

Завершает работу эмулятора.

    VFS:~$ exit

При вводе неизвестной команды выводится ошибка:

    VFS:~$ wrong
    Ошибка: неизвестная команда 'wrong'


## 5. Стартовый скрипт

Эмулятор может последовательно выполнять команды из
текстового файла.

Пример запуска:

    .\run.bat --script tests\start3.txt

Ошибочная команда не останавливает выполнение остальных
команд скрипта.


## 6. Виртуальная файловая система

Источником VFS является директория на диске.

При запуске структура директорий и содержимое файлов
загружаются в оперативную память. Исходная директория
не изменяется.

Пример:

    .\run.bat --vfs tests\vfs_deep

При успешной загрузке:

    VFS загружена

При неверном пути:

    Ошибка загрузки VFS


## 7. Тестирование

Для тестирования используются несколько вариантов VFS:

- `vfs_min` – минимальная VFS;
- `vfs_files` – VFS с несколькими файлами;
- `vfs_deep` – VFS с тремя и более уровнями вложенности.

Запуск тестов:

    .\tests\test_vfs_min.bat
    .\tests\test_vfs_files.bat
    .\tests\test_vfs_deep.bat
    .\tests\test_vfs_error.bat

Отдельная сборка проекта не требуется. Для работы необходим
Python 3.
